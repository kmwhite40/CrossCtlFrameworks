How deadlines are computed

Every number comes from FedRAMP's machine-readable consolidated rules (dataset {{ view.rules_version }}), not from Concord. Unchecked boxes are judgements, so the form starts with both reachability boxes ticked: the rules tell providers to assume exploitation can be automated unless there is evidence otherwise. The mitigation clock starts when the current rating and reachability were first recorded; re-saving the same evaluation does not restart it. Recording an evaluation can move a POA&M's due date earlier, never later; a later date is an extension and needs an approval.

CISA KEV matching reads CVE ids from each POA&M's title and weakness text, the same match the Security & Risk Intelligence page makes. N0 and N1 have no mitigation timeframe; VDR-TFR-RMN leaves them to routine operations.
