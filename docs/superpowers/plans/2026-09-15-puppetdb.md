# PuppetDB Connector Implementation Plan (CC&E #9)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read PuppetDB for what is running and whether desired state is actually being enforced — without writing to Puppet and without ever inferring a node's deletion.

**Architecture:** Two pure evaluators in a new posture provider, a `ConfigConnector` that fetches and dispatches them, and an idempotent additive inventory mapper over `boundary/service.py`.

**Tech Stack:** Python 3.12, httpx, SQLAlchemy 2 async, pytest. **No migration.**

**Spec:** `docs/superpowers/specs/2026-09-15-puppetdb-design.md`

## Global Constraints

- **No writes to Puppet.** No catalog compilation, no agent runs, no resource
  enforcement.
- **`sync_inventory` never deletes.** A node absent from a query was
  decommissioned, out of scope, *or truncated* — indistinguishable at the API
  boundary. `last_seen_at` going cold is the signal.
- **`capture()` returns `[]`.** Puppet facts are not ODP values, and inventing
  a mapping would be worse than nothing.
- **Never-reported is not a pass.** A node with no `report_timestamp`, or an
  unparseable one, is `manual_review_required`.
- **Evaluators are pure** — nodes in, findings out, `now` injected.
- **No new tables and no migration.**
- **Test database is on port 5434.** `CCF_DATABASE_URL=postgresql+asyncpg://ccf:ccf@localhost:5434/ccf_test CCF_DATABASE_URL_SYNC=postgresql+psycopg://ccf:ccf@localhost:5434/ccf_test`. Never two pytest sessions at once. App-driving scripts need `CCF_ENV=test`.
- Two rows wherever a filter is tested.
- `ruff check .` and `mypy src` clean; `alembic heads` unchanged at
  `0073_flaw_remediation`.
